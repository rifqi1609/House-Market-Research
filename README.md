## 📋 Project Overview
This project provides a comprehensive analysis of the residential real estate market in **Bekasi, Indonesia**. By leveraging web scraping and statistical analysis, it aims to demystify house pricing trends to help potential buyers make data-driven decisions.

## ⚠️ Problem Background
Buying a home is often a **once-in-a-lifetime decision** and one of the most significant financial commitments an individual will make. However, the sheer volume of options and price volatility can make finding the right home an exhausting and overwhelming process for buyers.

## 🎯 Project Objective
The primary goal of this research is to analyze house prices specifically within the **Bekasi** region using a sample of 200 listings from [rumah123.com](https://www.rumah123.com). 
* **Target:** Describe the current market condition.
* **Goal:** Provide actionable insights for prospective house buyers.

### Data Collection
* **Source:** [Rumah123.com](https://www.rumah123.com) (Filter: Bekasi).
